# 💠 ShopZone: The Pinnacle of Modern Commerce

**ShopZone** is an elite, high-fidelity luxury e-commerce platform built with **React**, **Vite**, and **Framer Motion**. It offers an immersive "Extreme Luxury" shopping experience with a deep obsidian aesthetic, cinematic animations, and specialized global concierge features.

## ✨ Key Features

### 🎨 Design & Aesthetics
- **Extreme Luxury Dark Theme**: A sophisticated slate-and-obsidian palette with Gold, Indigo, and Fuchsia accents.
- **Glassmorphism UI**: Semi-transparent containers with refined backdrop-filter effects.
- **Micro-animations**: Tactile hover effects, scale transitions, and layout morphing powered by Framer Motion.
- **High-Fidelity Typography**: A premium pairing of *Playfair Display* (Serif) and *Outfit* (Sans-serif).

### 🛍️ Shopping Experience
- **Boutique Collection**: A structured 3x3 grid layout fetching real-time product data from the DummyJSON API.
- **Dynamic Product Pages**: Deep-linked product views featuring high-res imagery, ratings, and detailed specifications.
- **Global Currency**: All pricing automatically localized and formatted in **INR (₹)**.
- **Persistent Cart**: A global state management system (Context API) synced with `localStorage` to ensure your selection survives page refreshes.

### 🔐 Security & Access
- **Private Access**: A dedicated fake authentication system with a "Guest Login" flow.
- **Protected Checkout**: Restricted route access for finalized purchases, requiring user authentication.
- **Elite Concierge**: A personalized contact system with prioritized message handling.

## 🛠️ Tech Stack

- **Core**: React 19 + Vite 8
- **Routing**: React Router 7 (Single Page Architecture)
- **State Management**: React Context API
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Styling**: Modern Vanilla CSS with CSS Variables

## 🚀 Getting Started

### Prerequisites
- Node.js (Latest LTS recommended)
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/shopzone.git
   cd shopzone
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
